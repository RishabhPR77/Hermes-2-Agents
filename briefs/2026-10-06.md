## M91 facts from today's snapshot to use
- `responseOptions`: two `SHARED` options (Approve/Reject) — first responder decides, others released
- `required: ["note"]` on Reject → auditable reason
- `callbackUrl` receives `answered` (immediate) and `closed` (final) events with HMAC-SHA256 signature
- `decision` set **only** by `SHARED` response — `PERSONAL`/"Seen" never becomes a decision
- `customId` names the condition; re-sending while open returns `deduplicated: true`
- No server-side `expiresIn` — sender owns the timeout, treats non-answer as safe default (usually "no")
- `close` with `404`/`403` = success (nothing to close)
- Channel = recipient list; no recipient field on send link; members must accept invite
- Severity: `HIGH` for approval gates (needs person now, phones only if channel dark)
