# Pinned topics

Topics the owner wants covered on a given date, regardless of day-to-day
scoring. Empty file with example rows = nothing pinned yet.

## Format

```
## <Short topic title>

- **Target date:** YYYY-MM-DD
- **Priority:** high | medium
- **Status:** planned | briefed | drafted | published | done
- **Notes:** who asked / why now
```
