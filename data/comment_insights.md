# Comment insights

Aggregated, deduplicated insights from `comments_inbox.md`. Sources are
anonymous; quote only with consent and under 15 words.

One section per insight, linked to the comment(s) that produced it.

## Insight format

```
## <insight>

- **Sources:** <channel + date + post>
- **Type:** question | objection/confusion | feature-or-integration request | sentiment
- **What people are saying:** 1–3 sentences
- **Why it matters for content:** e.g. "candidate brief", "confusion to clear
  up in an existing post", "FAQ candidate"
- **Reply drafts (need approval):** optional, marked "needs approval"

*Processed: YYYY-MM-DD*
```

Look for: questions people ask repeatedly; objections or confusion about what
M91 does; requests for integrations or features; sentiment shifts.

Never post reply drafts automatically — anything under "Reply drafts" is a
draft that requires human approval.
