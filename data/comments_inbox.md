# Comments inbox

Paste comments here to be surfaced to the Strategist. One entry per comment.

This file is the ONLY input for comments: never use a social/comment API.

## Format

```
## <channel> / <post or topic>

- **Date:** YYYY-MM-DD
- **Comment:** <verbatim text, up to a few paragraphs>

Repeat the bullet block for each comment.
```

## Example (delete me)

## Hacker News / "Show HN: wake a human when your agent wants to act"

- **Date:** 2026-10-01
- **Comment:** How does this compare to just paging the team on Slack? Feels
  like Slack plus a noise threshold would do the job.

---

*Anything here is anonymous unless explicitly named. The Strategist converts
new entries into `comment_insights.md`, then marks them processed (check ✓ at
the entry).*
